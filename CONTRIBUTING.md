# Contributing

Use the repository issue forms to nominate a blog, report a factual correction, or appeal a decision.

## Pull Requests

Ranking source changes must:

- cite public evidence;
- preserve the published category and track definitions;
- disclose material conflicts;
- avoid private analytics, credentials, signed URLs, or reviewer-only notes;
- pass the build and validation checks;
- leave generated files to the repository scripts.

Do not submit paid placement requests. They will be closed without ranking consideration.

## Editorial Review

A merged data change does not guarantee a particular rank. Scoring and ordering remain subject to the public methodology and conflict policy.
